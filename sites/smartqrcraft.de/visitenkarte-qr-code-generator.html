QR-Code für die Visitenkarte erstellen

Ein vCard-QR-Code enthält deine Kontaktdaten im Standardformat für digitale Visitenkarten. Das Handy des Scannenden bietet an, den Kontakt zu speichern.

  1. Trage Vorname und Nachname ein. Optional ergänzt du Firma, Position, Telefon, E-Mail und Webseite.
  2. Prüfe die Daten. Tippfehler landen sonst später in fremden Adressbüchern.
  3. Wähle Farbe und Design. Ein dunkler Code auf hellem Grund scannt am besten.
  4. Lade den Code als SVG für den Druck oder als PNG für Bildschirme herunter.
  5. Scanne den Code mit dem Handy und prüfe, ob der Kontakt richtig angelegt wird.

Je mehr Daten du eingibst, desto dichter wird das Muster. Für Visitenkarten reichen meist Name, Firma, Telefon, E-Mail und Webseite.

Größe und Platzierung auf der Visitenkarte

Die Größe entscheidet, ob der Code sich zuverlässig scannen lässt.

  • Mindestgröße: Empfohlen sind mindestens 2 × 2 cm. Optimal sind oft etwa 2,5 × 2,5 cm. Bei vielen Daten darf der Code gern größer sein.
  • Ort: Die Rückseite eignet sich gut, weil dort Platz für Rand und Aufforderung ist.
  • Aufforderung: Ein kurzer Text wie „Kontakt speichern“ erhöht die Chance, dass der Code gescannt wird.
  • Kontrast: Verwende dunkle Farben auf hellem Papier und vermeide Glanz-Lack direkt auf dem Code.
  • Test vor dem Druck: Drucke einen Probeabzug und scanne ihn mit mehreren Handys.

Datenschutz bei Kontaktdaten im QR-Code

Ein vCard-QR-Code enthält deine Daten im Klartext. Jeder, der die Karte oder den Code hat, kann sie auslesen. Nimm deshalb nur Angaben auf, die du auch auf der gedruckten Karte weitergeben würdest, und verzichte auf private Nummern, wenn du sie nicht teilen möchtest.

Dieser Generator erstellt den Code lokal in deinem Browser. Deine Eingaben werden nicht an unseren Server gesendet.
