WLAN QR-Code erstellen: Anleitung

Du brauchst nur den Netzwerknamen (SSID) und das Passwort deines WLANs.

  1. Trage im Generator den Netzwerknamen (SSID) genau so ein, wie er auf dem Handy angezeigt wird. Groß- und Kleinschreibung zählt.
  2. Gib das Passwort ein.
  3. Wähle die Verschlüsselung. Für die meisten Router ist WPA/WPA2/WPA3 richtig. Hat dein Netz kein Passwort, wähle Kein Passwort.
  4. Passe bei Bedarf Farbe und Design an und lade den Code als PNG oder SVG herunter.
  5. Scanne den Code mit einem anderen Handy und prüfe, ob die Verbindung klappt.

Wie verbinden sich Gäste mit dem WLAN?

Auf aktuellen iPhones und Android-Geräten genügt die normale Kamera-App. Man richtet sie auf den Code, tippt auf die eingeblendete Meldung und bestätigt die Verbindung. Eine zusätzliche App ist nicht nötig. Bei Android funktioniert das ab Android 10 zuverlässig.

WLAN-QR-Code direkt am Handy oder Router finden

Manche Geräte können den Code auch selbst anzeigen. Die Menünamen unterscheiden sich je nach Hersteller und Version.

  • Android: Ab Android 10 findest du bei den WLAN-Einstellungen neben dem verbundenen Netzwerk oft die Option QR-Code oder Teilen. Bei Samsung und Xiaomi heißen die Menüpunkte teils anders.
  • iPhone: Das iPhone zeigt in den Einstellungen keinen QR-Code für das eigene WLAN an. Du kannst das Passwort aber per Teilen-Funktion an ein Gerät in der Nähe senden, oder du erstellst den Code mit diesem Generator.
  • Router: Bei manchen Routern, etwa der FRITZ!Box im Bereich Gastzugang, gibt es einen fertigen QR-Code.

Sicherheit: Was du beachten solltest

Ein WLAN QR-Code schützt dein Passwort nicht. Er enthält es nur in codierter Form, und jeder, der den Code scannt, kann sich verbinden.

  • Gastnetz verwenden: Wenn dein Router ein Gast-WLAN bietet, erstelle den Code dafür statt für dein Heimnetz.
  • Zugang begrenzen: Hänge den Code nur dort auf, wo er hingehört, etwa im Gästebereich.
  • Passwort ändern: Wenn der Code in falsche Hände gerät, ändere das WLAN-Passwort und erstelle einen neuen Code.
  • Keine Daten hochgeladen: Dieser Generator erstellt den Code lokal in deinem Browser.
