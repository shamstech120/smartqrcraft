Print-Ready

Make a Code That Actually Scans

A QR code that looks good on screen can still fail on a small sticker or a worn menu. A few settings decide whether people can scan it.

  • Contrast. Dark code on a light background is the safest. The generator warns you when the contrast is too low.
  • Size. Aim for about one tenth of the scanning distance, and at least about 2 cm (0.8 in) for cards. See the QR code size guide.
  • Border. Keep a blank margin of at least four modules around the code. That is the default here, and you can change it.
  • Error correction. Choose Low, Medium, Quartile or High. Higher levels survive more damage and are used automatically when you add a logo.
  • File format. Use SVG, PDF or EPS for print and a large PNG for screens. All are free.
  • Test. Use the QR code tester and scan a printed copy with two phones.
