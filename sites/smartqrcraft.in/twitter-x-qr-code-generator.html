How to make an X QR code

  1. Type your username, with or without the @.
  2. Or, to get people posting, write a pre-filled post with your hashtag or event name. This replaces the profile link.
  3. Choose colors and a frame such as "Follow us", then download.
  4. Scan the finished code with two different phones (for example an iPhone and an Android) before you print it.

Tips

  • Use one hashtag. A short post with a single tag is more likely to be shared unchanged.
  • People can edit the post before they share it, and nothing is posted without them.
  • Links still say twitter.com in some places. Both x.com and twitter.com addresses open the same profile.
