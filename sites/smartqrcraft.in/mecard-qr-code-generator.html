MeCard vs vCard

Both formats save a contact to the phone. The difference is size and how much they can hold.

MeCardvCard
Code densityLower (smaller data)Higher
FieldsName, phone, email, website, addressAlso company, job title, several numbers and more
SupportMost Android scanners and many apps; test on iPhoneVery wide, including the iPhone camera
Best forTiny codes, stickers, badgesBusiness cards and anything formal

How to make a MeCard QR code

  1. Fill in your first and last name. Every other field is optional.
  2. Add a phone number with the country code, an email and a website.
  3. Download the code and scan it with both an iPhone and an Android before printing.

Which one should you use?

If you need a very small code, or your audience mostly uses Android, MeCard is a good fit. If you are not sure, the vCard QR code generator is the safer choice because nearly every phone camera supports it.
