QR Code Size Guide: How Big Should a QR Code Be?

A QR code that is too small will not scan, and one that is too big wastes space. Use this guide to choose a size for cards, menus, posters and stickers.

The 10:1 rule of thumb

A widely used guide is that the QR code should be about one tenth of the distance it will be scanned from. If people scan from 30 cm (12 inches), aim for about 3 cm (1.2 inches). If they scan from 2 metres (6.5 feet), aim for about 20 cm (8 inches).

It is a starting point, not a law. Longer content, low contrast, poor lighting and cheap printing all need more size.

What makes a code need more size

The same physical size can be fine for one code and too small for another.

  • More content. A long link creates more, smaller modules, so it needs more space. Shorten links where you can.
  • A logo. A center logo raises the error correction level, which also adds density. Keep the logo small.
  • Low contrast. Pale colors or a busy background make scanning harder at any size.
  • Poor print quality. Blurry edges and low resolution hurt small codes the most.
  • Surface and angle. Curved, glossy or angled surfaces need a bigger code.

Do not forget the quiet zone

The blank margin around the code is called the quiet zone. The QR specification calls for at least four modules of empty space on every side. Cropping it, or letting a border or picture touch the code, is a common cause of failed scans. This site's generators add a four-module margin by default.

File format and resolution

For print, use SVG, which stays sharp at any size. If you use PNG, export a large size (2048 or 4096 px) and do not enlarge a small image. Keep proportions and never stretch the code.

Print checklist

  1. Choose the size from the table, based on the real scanning distance.
  2. Check contrast: dark code, light background.
  3. Keep the quiet zone clear.
  4. Print a test at the final size on the real material.
  5. Scan it with at least two phones, at the real distance and in the real lighting.
  6. Then print the full run.
