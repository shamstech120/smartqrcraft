How to make a text message QR code

  1. Type the mobile number with its country code.
  2. Write a short message, for example a keyword such as "JOIN" or "Book a table for Friday".
  3. Choose colors and a frame like "Text us", then download.
  4. Scan the finished code with two different phones (for example an iPhone and an Android) before you print it.

How it works

The code uses the widely supported SMSTO: format, which holds a number and a message. The person's messaging app opens with both filled in, and nothing is sent until they tap Send. Normal text message charges from their carrier apply.

Before you use SMS for marketing

If you use texts for marketing, the person must agree to receive messages and must be able to opt out. Rules differ by country, for example the TCPA in the US and PECR in the UK. The QR code itself only starts a message the person chooses to send; what you do with the number afterwards is where the rules apply.
