How to make a QR code for a phone number

A calling QR code stores your number in the standard tel: format that phones understand.

  1. Type the number with the country code, for example +1 for the US, +44 for the UK or +91 for India.
  2. Choose colors and a frame such as "Call us", and add your logo if you want.
  3. Download PNG for screens and documents, or SVG for print.
  4. Scan the finished code with two different phones (for example an iPhone and an Android) before you print it.

What happens when someone scans it

The phone camera reads the code and shows a prompt such as "Call +1 555 019 2834". The call only starts when the person taps it. A QR code cannot place a call on its own, which is a good thing: people stay in control.

Spaces, dashes and brackets are removed automatically, because phones expect only digits and a leading plus sign.

Tips for phone QR codes

  • Print the number too. Some people prefer to dial, and it builds trust to see where the call goes.
  • Say when you answer. "Scan to call, Mon to Fri 9 to 5" avoids missed calls.
  • Want a chat instead? A text message QR code or a WhatsApp code may suit people who dislike calls.
  • Size: about 2 cm (0.8 in) is enough for a card, larger for signs read from a distance. See the size guide.
