WiFi codes: the biggest time saver

A WiFi code removes the most common question you get. Print it on a card by the entrance or in a frame in the living area. If your router offers a guest network, use that one, so guests do not join the network your own devices use.

Remember that a WiFi code contains the password in readable form for anyone who scans it. Place it in guest areas, and change the password if the printed code gets out.

Creating a guest guide that works on a phone

Guests read on their phones, often on the go.

  • Keep it short and sectioned: arrival, WiFi, house rules, appliances, transport, food, emergencies, checkout.
  • Use a mobile-friendly page or a compact PDF with large text.
  • Add a phone number for emergencies as plain text too.
  • Keep the address stable, and update the page when things change.
  • Offer the guide in the languages your guests speak.

Asking for reviews

A review code on the checkout card or in a thank-you message makes it easy for guests to review you on Google. Ask every guest, and do not offer a reward for a review, since platforms prohibit incentives.

Practical tips

  • Print at least 3 cm (1.2 in) wide, and laminate codes in kitchens and bathrooms.
  • Label each code, for example "Scan for WiFi".
  • Test after each change. If you change the WiFi name or password, make a new code.
  • Use codes as a supplement, not a replacement. Keep essential information on paper too.
