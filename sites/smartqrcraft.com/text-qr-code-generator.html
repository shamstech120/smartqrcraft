How to turn text into a QR code

  1. Type or paste your text into the box.
  2. Watch the preview: the more text, the denser the code.
  3. Download PNG or SVG.
  4. Scan it once to check the text shows correctly, including any special characters.

How much text fits?

A QR code can technically hold a few thousand characters, but dense codes are hard to scan. As a rule of thumb:

Text lengthResult
Up to about 100 charactersSimple code, scans easily even small
100 to 300 charactersFine at normal print sizes
300 to 1,000 charactersDense; print larger and test carefully
More than 1,000Not recommended. Put the text on a web page and link to it instead

Is the text private?

The text is written into the image itself, so anyone who scans the code can read it. Do not put passwords or personal data in a text code that others might see. This generator runs in your browser, so the text is not sent to our server.
