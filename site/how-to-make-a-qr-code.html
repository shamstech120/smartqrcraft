How to Make a QR Code (Free, Step by Step)

You can make a QR code in about a minute, free, without an account. Here are the four steps, the quickest method for each device, and the checks that stop a printed code from failing.

How to create a QR code in 4 steps

The fastest way is a free online QR code generator, which works in any browser on a phone or computer:

  1. Choose what the code does. Open a QR code generator and pick a type: a website link, WiFi, a contact card, a phone number, an email and more.
  2. Enter the content. Paste the link, or fill in the WiFi name and password or your contact details.
  3. Style it (optional). Change the color, add a frame such as "Scan me" or put your logo in the middle. Keep the code dark on a light background.
  4. Download and test. Save it as PNG for screens or SVG/PDF for print, then scan it with your phone before you share or print it.

That is all a QR code is: a picture that stores text, such as a web address, which a phone camera can read. You do not need to register the code anywhere, and a code that stores its content directly (a static QR code) keeps working forever.

How to make a QR code for a link or website

  1. Open the page you want to share and copy the address from the browser's address bar.
  2. Paste it into the URL field of the generator. If you leave out https://, it is added for you.
  3. Download the code. When someone scans it, the page opens on their phone.

Short links make simpler codes that print smaller. If the page might move, link to an address on your own domain, such as yourname.com/menu, and change where that address points instead of reprinting. The static vs dynamic guide explains the options.

How to get a QR code for your business

Most businesses start with three codes: a link to the menu, price list or website; a WiFi code for customers; and a link to leave a Google review. For reviews, copy your review link from Google Business Profile and turn it into a styled code with your logo.

Print codes where people already wait or decide: tables, counters, windows, receipts and packaging. Add a short line that says what happens, such as "Scan for today's menu". Ready-made layouts are in the printable templates.

Design tips that keep the code scannable

  • Contrast first. A dark code on a white or light background scans best. Light-on-dark codes fail in some apps.
  • Leave a border. Keep a blank margin (the quiet zone) around the code.
  • Keep logos small. A centre logo works because of error correction, but only up to a point.
  • Say what it does. A frame with a call to action gets more scans than a bare code.
  • Match the size to the distance. About 2 cm (0.8 in) for cards; much larger for posters. See the size guide.

Test the code before you print or share it

Scan the finished code with two different phones, for example an iPhone and an Android. Check that it opens the right page on mobile data, not just on office WiFi. For printed codes, print one copy at the real size first. The QR code tester also checks whether a code still reads when it is small or blurry.

Common mistakes

  • A typo in the link. Once printed, it cannot be fixed.
  • Using a free trial's dynamic code. Some services switch codes off when a trial ends. Codes made here are static and never expire.
  • Printing too small or on a curved or glossy surface.
  • Linking to a page that is not mobile-friendly, since nearly every scan comes from a phone.
  • No instructions. People need a reason to scan.
