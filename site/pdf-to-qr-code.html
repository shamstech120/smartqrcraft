How does a PDF QR code work?

A QR code cannot hold a whole PDF file. It stores a short web address, and the PDF lives online at that address. When someone scans the code, their phone opens the link, and the PDF displays in the browser or the phone's document viewer.

So converting a PDF to a QR code has two parts: put the PDF online, then turn its link into a QR code. This tool does the second part. It does not upload or store your file.

How to turn a PDF into a QR code

Six quick steps.

  1. Put the PDF online. Upload it to your own website, or to cloud storage such as Google Drive, Dropbox or OneDrive.
  2. Make the link public. For cloud storage, set sharing to "anyone with the link can view" so scanners are not asked to sign in.
  3. Copy the link to the file.
  4. Paste it into the field above. The QR code appears instantly.
  5. Style and download the PNG (screens, documents) or SVG (print).
  6. Test with a phone that is not signed in to your accounts, to see what a stranger would see.

Updating the PDF later

Because the QR code holds the link and not the file, you can swap the document without reprinting, if you do it carefully.

  • Replace the file at the same address rather than uploading a new one with a new link.
  • In Google Drive, use the option to manage versions or replace the file so the link stays the same.
  • If the link has to change, create a new QR code and update anywhere the old one is printed.

Tips for a PDF that scans and opens well

A good code is only half the job. The PDF has to open well too.

  • Keep the file small. Compress large images so it loads quickly on mobile data.
  • Design for a phone screen. Portrait pages with readable text work better than wide layouts.
  • Use a clear file name. A descriptive name helps if someone saves or shares it.
  • Print the code at least about 1 inch (2.5 cm) wide with blank space around it.
  • Do not put sensitive files behind a public link. Anyone who scans, or gets the link, can open it.
