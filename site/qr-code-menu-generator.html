How a QR code menu works

A menu QR code is a link in scannable form. The code contains the web address of your menu, and when a guest points their phone camera at it, their phone opens that address. The menu itself lives somewhere online: a PDF on your website, a page on your site, or a file in cloud storage.

This tool creates the QR code. It does not host the menu file, so you need a link first. That is a benefit as well as a limit: your menu stays under your control, and you can update it without touching the printed code.

How to make a QR code menu

Six steps, and most of the time goes into getting the menu online.

  1. Get your menu online. Export it as a PDF (in most word processors, choose Print, then Save as PDF) and upload it to your website, or publish it as a web page.
  2. Copy the link to the menu. For cloud storage such as Google Drive or Dropbox, set sharing to "anyone with the link can view" first.
  3. Paste the link into the field above.
  4. Pick colors that match your branding, keep strong contrast, and optionally add the frame text "Scan for menu".
  5. Download the PNG or SVG and place it on tables, windows and takeout packaging.
  6. Scan it on both an iPhone and an Android phone to check the menu loads quickly and reads well.

PDF menu or web page menu?

Both work with a static QR code. The difference is what happens after the scan.

How to update your menu without reprinting

This is the most important habit for a static QR code menu. Keep the link the same and change what is behind it.

  • If your menu is a PDF, overwrite the file on your host using the exact same file name and address.
  • If you use cloud storage, replace the file rather than deleting and re-uploading it, since a new upload can create a new link.
  • If your menu is a web page, edit the page and keep its address unchanged.
  • Only regenerate the QR code if the link itself changes.

Menu QR code best practices

Small details decide whether guests enjoy the experience or give up and ask for paper.

  • Keep it mobile-friendly. Use readable font sizes and avoid multi-column layouts that force pinching and zooming.
  • Keep the file small. A heavy PDF loads slowly on weak restaurant WiFi or mobile data. Compress images before exporting.
  • Print it big enough. Aim for at least about 1 inch (2.5 cm) square on a table tent, larger on windows.
  • Say what it is. Add "Scan for menu" so guests do not guess.
  • Offer a paper option. Some guests prefer not to scan, so keep a few printed menus or mention that staff can help.
  • Include allergen and dietary notes in the menu itself where you can.
