How to Make a QR Code in Canva

Canva has a built-in QR code generator for links, with static and dynamic options. Here is how to use it, what needs a paid plan, how Adobe Express compares, and how to add WiFi, contact or payment codes that Canva cannot make.

Quick answer

  1. Open your design in Canva.
  2. Go to Elements and search "QR code" (or open Apps and search for QR codes).
  3. Choose Create static for a fixed link, or Create dynamic for a link you can change later.
  4. Paste your link, adjust the colors and corners, and generate the code. It is added to your page.
  5. Export the design as PDF (print) or PNG, and scan the result before printing.

Canva's menus change from time to time, so the labels you see may differ slightly.

Customizing the code in Canva

You can change the code's colors and corner style. Keep the code dark and the background light, do not stretch it out of proportion, and do not place it over a busy photo. Transparency, shadows and effects on the code itself make it harder to scan.

Adding WiFi, contact, payment or other codes to Canva

Canva's generator makes codes for web links. For other types, create the code here and import it:

  1. Make the code: WiFi, contact card, phone, email and more, with your colors and logo.
  2. Download it as SVG, which stays sharp at any size (PNG at 2048 px also works).
  3. In Canva, open Uploads, upload the file and drag it into your design.
  4. Resize it by the corner handles only, and keep a blank margin around it.

How to make a QR code in Adobe Express

Adobe Express has a free QR code generator too. Open it, paste a link, pick a style and colors, and download the code as PNG, JPG or PDF, or open it in the Adobe Express editor to add it to a design. Adobe states that its codes are for links only and do not expire, which is how static codes work.

Canva QR code not scanning? Check these

  • Too small in the export. Print at least 2 cm (0.8 in) wide for handheld items.
  • Low contrast between the code and the background, or a light code on a dark background.
  • Something overlaps the code: text, a shape, a photo edge or a fold line.
  • The code was cropped or stretched unevenly.
  • Low-resolution export. Use PDF Print or a large PNG.
  • Still stuck? Upload the exported image to the QR code tester.
