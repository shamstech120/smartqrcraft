How to make an email QR code

  1. Enter the address that should receive the email.
  2. Add a subject, for example "Quote request" or "Feedback: table 12", so you can sort replies easily.
  3. Optionally add a message. Keep it short; the sender can still edit it before sending.
  4. Style the code, then download PNG or SVG.
  5. Scan the finished code with two different phones (for example an iPhone and an Android) before you print it.

How an email QR code works

The code stores a standard mailto: link with the subject and message attached. When scanned, the phone opens its default mail app with everything filled in. Nothing is sent until the person taps Send.

The person needs a mail app set up on their phone. Most people have one, but for audiences that may not, a link to a contact form is a safe alternative.

Tips

  • Use a shared inbox such as hello@ or support@, not a personal address that may change.
  • Long messages make dense codes. A short subject and one line of text keep the code easy to scan.
  • Tell people what happens: "Scan to email us" under the code sets the right expectation.
