QR Codes in Print: How to Print a QR Code That Always Scans

Most QR code problems start at the printer, not the generator. This guide covers the file to send, the size to choose and the details that matter on flyers, cards, clothing, packaging and signs.

The 8-point print checklist

  1. Size: at least 2 cm (0.8 in) for items held in the hand. For distance, use about one tenth of the scanning distance. See the size guide.
  2. Quiet zone: keep a blank border of 4 modules around the code. Do not let text, borders or folds cut into it.
  3. Contrast: dark code on a light background. Light-on-dark and inverted codes fail on some scanners.
  4. Short content: shorter links make fewer, bigger modules that tolerate print errors.
  5. Error correction: use level Q or H for rough surfaces, fabric, or when you add a logo.
  6. No stretching: scale the code evenly; never squash it to fit a space.
  7. Proof at full size: print one copy at real size and scan it with an iPhone and an Android.
  8. Test the destination: make sure the link works on mobile data, not just office WiFi.

Printing a QR code on a t-shirt

Fabric stretches and folds, which bends the grid. Use a large code, square modules (not dots), high error correction and a plain light area of the shirt. Screen printing and DTF transfers keep edges crisp. Embroidery can work only for big codes with few modules, so test a sample before ordering in bulk.

QR codes on packaging

Put the code on a flat face of the box, away from seams, folds and barcodes that a checkout scanner reads. Glossy film and shrink wrap cause glare, so use higher contrast and a slightly larger size. If the code will be on shelves for years, link to a page on your own domain so you can change the content without reprinting.

Colors and CMYK

Choose a code color that stays dark when printed in CMYK. A bright screen color can print lighter than expected. Aim for a contrast ratio of at least 4:1 between code and background; our generator warns you when contrast is low. Avoid metallic inks, gradients that fade to light shades, and backgrounds with patterns behind the code.
