Serial Number QR Code Generator

Open Make a numbered list, set a prefix and a number range, and get one QR code per serial number, all in a single ZIP with a CSV index.

How to make numbered QR codes

  1. Click Make a numbered list (serial numbers) in the tool.
  2. Set a prefix such as SN- or INV-2026-, the first and last number, and the number of digits (0001).
  3. Click Fill the list. Each line becomes one QR code.
  4. Choose color, size and PNG or SVG, then Generate QR codes and Download ZIP.
  5. Print them on labels with the printable templates, or give the ZIP to your printer.

Tips for serial QR codes

  • Keep the serial printed too. Print the number as text next to each code for people and for checking.
  • Use the CSV. The ZIP includes manifest.csv listing each file and its content, useful for stock sheets.
  • Linking to pages? A prefix like https://yoursite.com/p/ gives each item its own page you control.
  • Up to 1,000 codes per batch. For more, run several batches with different ranges.
