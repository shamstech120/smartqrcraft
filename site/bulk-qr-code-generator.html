How to make QR codes in bulk

The tool creates one static QR code per line of your list.

  1. Put one item per line in the box above: a link, a product page, a table URL, or any text. Or click Load CSV or TXT file.
  2. If you want your own file names, switch the line format to Name, content and write each line as name,content.
  3. Choose color, size (PNG) or vector output (SVG), and style.
  4. Click Generate QR codes. A preview of the first codes appears.
  5. Click Download ZIP. You get every QR code plus a manifest.csv that lists each line and its file name.

Tips for large batches

A few habits keep a big batch from turning into a big mistake.

  • Test a few first. Generate a small batch, print or display two or three, and scan them before you commit.
  • Keep links short. Shorter content makes simpler codes that scan better at small sizes.
  • Use unique, stable links. These are static codes, so you cannot change a link after printing. Point them at pages you control.
  • Check the manifest. It shows which line produced which file, so you can match codes to items.
  • Use SVG for print. Vector files stay sharp at any size, and PNG is easier for documents and screens.
  • Batch size. This tool handles up to 1000 lines at a time. Split larger lists into several files.

What this tool does not do

Static codes contain their content directly, so there is no scan tracking, no editing after printing and no account. If you need to change a destination later or count scans, you would need a dynamic QR service. For fixed links, static codes are free, permanent and need no server.

Every line is encoded exactly as written. Check your list for typos and stray spaces, because the tool will not correct them.
