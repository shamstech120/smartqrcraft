How to find your LinkedIn QR code in the app

LinkedIn already gives every member a personal QR code inside the mobile app. It only works for personal profiles, and the app has to be installed on your phone. These steps match LinkedIn's own help page, though the menu labels can shift slightly between app versions.

  1. Open the LinkedIn app and tap the search bar at the top of the home screen.
  2. Tap the QR code icon at the right end of the search bar.
  3. Open the My code tab. Your personal QR code appears on screen.
  4. Tap Share my code or Save to photos (Android shows a save-to-gallery option).

To scan someone else's code, open the same screen and choose the Scan tab, or import a saved image with the scan-from-photos option. The regular phone camera also opens LinkedIn codes on most current phones.

Why make a custom LinkedIn QR code instead?

The in-app code is fine for showing your screen at an event. It falls short when you want to put a code on paper or a slide. It is a screenshot you cannot recolor, it cannot point to a company page, and it lives inside the app, so you cannot generate it from a laptop.

A custom code from a generator fixes those gaps. You paste any LinkedIn URL, choose your colors, add a logo or a short call to action, and download a print-ready PNG or a scalable SVG. The code is static, meaning the link is stored inside the pattern itself. There is no account, no expiry date, and no tracking layer between the scan and your page.

How to create a LinkedIn QR code

It takes about a minute and needs nothing but your link.

  1. Open LinkedIn and copy your profile URL. On a computer, view your profile and copy the address bar. It looks like linkedin.com/in/your-name. For a company, use the linkedin.com/company/your-company address.
  2. Paste it into the field above. The QR code appears instantly.
  3. Pick a color and style. Keep strong contrast: a dark code on a light background scans most reliably.
  4. Optional: turn on the frame to add text like "Connect on LinkedIn", or add a square logo.
  5. Download the PNG for documents and screens, or the SVG for print and signage.
  6. Test it with your phone camera before it goes anywhere public.

Tip: if you have not customized your LinkedIn URL, consider doing that first (Edit public profile & URL in your profile settings). A shorter, cleaner link also makes a simpler, easier-to-scan code, and changing it later would break any code you already printed.

Tips for a LinkedIn QR code that actually gets scanned

A code that looks good but fails in the real world is worse than no code. A few habits prevent that.

  • Size: keep printed codes at least about 1 inch (2.5 cm) wide, and larger for anything read from a distance.
  • Contrast: use a dark code on a light background. Avoid light-on-dark inversions and low-contrast brand colors.
  • Logo: keep any center logo small. This tool raises error correction automatically when you add one.
  • Say what it does: a line like "Scan to connect on LinkedIn" beats a bare code.
  • Check the destination: scan the final file on both an iPhone and an Android phone before printing.
