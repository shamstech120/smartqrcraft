How to create a WiFi QR code

You need the exact network name and password of the WiFi you want to share.

  1. Type the network name (SSID) exactly as it appears on a phone, including capital letters, spaces and symbols.
  2. Enter the password.
  3. Choose the security type. Most routers use WPA/WPA2/WPA3, so keep the default unless you know otherwise. If your network has no password, choose No password.
  4. If your network name is hidden, set Hidden network to Yes.
  5. Pick a style, download the PNG or SVG, and print it or show it on a screen.
  6. Scan the code with another phone to confirm it joins the network.

How guests connect

Guests open the normal camera app and point it at the code. A prompt appears with the network name and an option to join, and one tap connects them. No extra app is needed. This works on current iPhones and on Android phones from Android 10, and many older Android phones can do it through Google Lens or a scanner app.

You can check how the code behaves first with the QR code scanner, which shows the network name and security type stored in the code.

Find a WiFi QR code you already have

Some devices can already show a code for the network you are on.

  • Android: on Android 10 and newer, open the WiFi settings, tap the connected network and look for a QR code or Share option. Menu names differ by manufacturer.
  • iPhone: iOS does not show a QR code for the network. You can share the password with a nearby Apple device from the password prompt, or create a code here.
  • Router: some routers, including many consumer models, show a WiFi QR code in the admin page, often in the guest network settings.

Security: what to know before you print

A WiFi QR code does not hide the password. It holds it in a form a phone can read, and anyone who scans the code can join.

  • Use a guest network if your router has one, so visitors never touch the network your own devices use.
  • Place the code where guests are, not on a public window facing the street.
  • Change the password if the printed code gets shared too widely. Then make a new code.
  • Use WPA2 or WPA3 for the network itself, and a strong password.
  • Nothing is uploaded here. The code is created in your browser and your password is not sent to a server.

Printing and placing the code

A little care makes the code scan every time.

  • Print at least 3 cm (1.2 in) wide for a table card, larger on a wall. See the QR code size guide.
  • Keep a clear white margin around the code and dark-on-light colors.
  • Add a short label such as "Scan to join WiFi", and the network name in text as a backup.
  • Laminate codes in kitchens or bars where they get wet or dirty.
  • Test the printed card with an iPhone and an Android phone before you use it.

If the code does not connect

Almost every problem is one of these.

  • The network name or password is wrong. Both are case sensitive. Compare them with what the router shows.
  • The wrong security type is selected. Try WPA/WPA2/WPA3.
  • The network is hidden but Hidden network is set to No.
  • The password contains special characters. The tool encodes them, but retype the password carefully and test it.
  • The phone is too old to read WiFi codes with its camera. Try a scanner app.
  • You changed the password after making the code. Make a new one.
