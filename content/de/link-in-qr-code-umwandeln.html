Hilfe

Dein QR-Code wird lokal in deinem Browser erstellt. Es werden keine Daten an einen Server gesendet.

So machst du aus einem Link einen QR-Code

  1. Kopiere die Adresse aus der Adresszeile deines Browsers.
  2. Füge sie oben ein. Fehlt https://, ergänzen wir es automatisch.
  3. Wähle Farben, einen Rahmen mit Text und bei Bedarf dein Logo.
  4. Lade PNG für Bildschirme oder SVG und PDF für den Druck herunter.
  5. Scanne den Code einmal zur Kontrolle, bevor du ihn verteilst.

Kurze Links machen bessere QR-Codes

Je länger die Adresse, desto dichter wird der Code und desto größer musst du ihn drucken. Lange Adressen mit vielen Parametern lohnen sich zu kürzen. Am besten nutzt du eine kurze Adresse auf deiner eigenen Domain, etwa deinefirma.de/flyer, und leitest sie auf die lange Seite weiter. So bleibt der Code klein und dauerhaft gültig.

Link vor dem Druck prüfen

  • Funktioniert die Seite am Handy? Die meisten Scans kommen vom Smartphone.
  • Bleibt die Adresse gültig? Aktionsseiten werden oft gelöscht, dann führt der Code ins Leere.
  • Stimmt die Schreibweise? Ein Tippfehler im Link ist nach dem Druck nicht mehr zu korrigieren.
