Was ist ein GiroCode?

Der GiroCode ist ein QR-Code für SEPA-Überweisungen nach dem EPC-Standard. Er enthält Empfängername, IBAN und optional Betrag, Verwendungszweck und BIC. Scannt ein Zahler den Code mit seiner Banking-App, wird die Überweisung automatisch ausgefüllt, ohne dass er die IBAN abtippen muss.

Dieses Tool erstellt den Code lokal in deinem Browser. Deine Bankdaten werden nicht an einen Server gesendet. Es ist kein offizieller Dienst einer Bank.

GiroCode erstellen: Anleitung

Du brauchst nur die Daten, die auf einer Rechnung stehen.

  1. Trage den Namen des Empfängers ein, so wie er beim Konto hinterlegt ist.
  2. Gib die IBAN ein. Das Tool prüft die Prüfsumme und meldet Tippfehler, indem es keinen Code anzeigt.
  3. Optional: Betrag in Euro, etwa für eine Rechnung. Lässt du ihn leer, gibt der Zahler den Betrag selbst ein.
  4. Optional: Verwendungszweck, zum Beispiel die Rechnungsnummer. Er ist auf 140 Zeichen begrenzt.
  5. Optional: BIC. Innerhalb des SEPA-Raums reicht meist die IBAN.
  6. Lade den Code als PNG oder SVG herunter und teste ihn mit der Banking-App vor dem Druck.

Sicherheit und Grenzen

Ein GiroCode enthält Zahlungsdaten und sollte sorgfältig verwendet werden.

  • Zahler sollten den Empfänger prüfen. Banking-Apps zeigen Name und IBAN vor der Freigabe an.
  • Aufkleber nicht überkleben. Ein falscher Code über einem echten kann Zahlungen umleiten.
  • Nur SEPA und Euro. Der Code eignet sich für Überweisungen im SEPA-Raum in Euro.
  • Nicht alle Apps unterstützen das Scannen. Viele Banking-Apps können GiroCodes lesen. Prüfe es mit deiner eigenen App.
  • Rechnungsdaten bleiben deine Verantwortung. Prüfe Name, IBAN und Betrag, bevor du den Code verwendest.
