QR-Code Widget für deine Website

Füge zwei Zeilen HTML ein, und deine Seite zeigt einen QR-Code von sich selbst. Besucher am Computer scannen ihn und lesen am Handy weiter. Funktioniert mit WordPress, Shopify, Wix, Jimdo und normalem HTML.

So bindest du das Widget ein

  1. Wähle oben die Einstellungen: automatisch (die aktuelle Seite) oder ein fester Link, Größe, Farbe und Beschriftung.
  2. Klicke auf Code kopieren.
  3. Füge den Code dort in deine Seite ein, wo der QR-Code erscheinen soll, zum Beispiel in die Seitenleiste, den Footer oder eine Produktseite.
  4. Öffne die Seite und scanne den Code mit dem Handy.

Wo du den Code einfügst

Datenschutz und Ladezeit

Das Widget ist ein einzelnes kleines Skript ohne Cookies, ohne Tracking und ohne Aufrufe anderer Dienste. Der QR-Code wird im Browser des Besuchers gezeichnet, Seitenadressen werden nicht an uns oder Dritte gesendet. Das Skript lädt mit async und bremst deine Seite nicht aus.

Beim Laden des Skripts von unserem Server wird wie bei jeder eingebundenen Datei die IP-Adresse des Besuchers übertragen. Erwähne das Widget deshalb in deiner Datenschutzerklärung, oder lade die Datei embed.js herunter und binde sie von deinem eigenen Server ein.
