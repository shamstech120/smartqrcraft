Warum funktionieren manche kostenlosen QR-Codes plötzlich nicht mehr?

Viele Anbieter erstellen im Testzeitraum dynamische QR-Codes. Solche Codes enthalten nicht deinen Link, sondern eine Kurz-Adresse des Anbieters, die erst weiterleitet. Endet die Testphase oder das Abo, schaltet der Anbieter die Weiterleitung ab oder zeigt eine Seite mit Zahlungsaufforderung. Die gedruckten Codes sind dann nutzlos.

Ein statischer QR-Code enthält den Inhalt selbst, also zum Beispiel deinen Link, deine WLAN-Daten oder deine Kontaktdaten. Er hängt von keinem Server ab und kann deshalb nicht abgeschaltet werden.

So erkennst du, ob dein QR-Code dauerhaft ist

  1. Scanne den Code mit unserem QR-Code Scanner. Er zeigt den Inhalt, ohne ihn zu öffnen.
  2. Steht dort deine eigene Adresse (zum Beispiel deinefirma.de/speisekarte) oder deine WLAN- bzw. Kontaktdaten, ist der Code statisch und dauerhaft.
  3. Steht dort eine fremde Kurz-Adresse eines QR-Anbieters, ist der Code dynamisch und hängt von diesem Anbieter ab.

Tipp: dauerhaft und trotzdem änderbar

Du willst den Inhalt später ändern können, ohne neu zu drucken? Erstelle einen statischen Code für eine Adresse auf deiner eigenen Domain, zum Beispiel deinefirma.de/menu. Wohin diese Adresse führt, stellst du auf deiner Website ein. Der gedruckte Code bleibt dauerhaft gültig, solange dir die Domain gehört.
