Gib eine Handynummer ein, um den QR-Code zu erstellen.
Hilfe

Dein QR-Code wird lokal in deinem Browser erstellt. Es werden keine Daten an einen Server gesendet.

So erstellst du einen SMS-QR-Code

  1. Gib die Handynummer mit Ländervorwahl ein, zum Beispiel +49 151 23456789.
  2. Schreibe eine kurze Nachricht, etwa "Tisch für Freitag reservieren".
  3. Wähle Farben und einen Rahmen wie "Schreib uns" und lade den Code herunter.
  4. Scanne den fertigen Code vor dem Druck mit zwei verschiedenen Handys, zum Beispiel einem iPhone und einem Android-Gerät.

So funktioniert es

Der Code nutzt das weit verbreitete Format SMSTO: mit Nummer und Nachricht. Die SMS-App öffnet sich mit beidem, gesendet wird erst nach einem Tipp auf Senden. Es fallen die normalen SMS-Kosten des Absenders an.

Wichtig bei SMS-Werbung

Wenn du Nummern für Werbe-SMS nutzen willst, brauchst du in Deutschland eine ausdrückliche Einwilligung, und Empfänger müssen sich jederzeit abmelden können. Der QR-Code selbst öffnet nur eine Nachricht, die die Person bewusst sendet. Was du danach mit der Nummer machst, unterliegt dem Datenschutz- und Wettbewerbsrecht. Lass dich im Zweifel beraten.
