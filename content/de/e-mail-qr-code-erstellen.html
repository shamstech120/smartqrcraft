Hilfe

Dein QR-Code wird lokal in deinem Browser erstellt. Es werden keine Daten an einen Server gesendet.

So erstellst du einen E-Mail-QR-Code

  1. Gib die Adresse ein, an die die E-Mail gehen soll.
  2. Lege einen Betreff fest, zum Beispiel "Angebotsanfrage" oder "Feedback: Tisch 12". So kannst du Antworten leicht sortieren.
  3. Schreibe bei Bedarf eine kurze Nachricht. Der Absender kann sie vor dem Senden noch ändern.
  4. Gestalte den Code und lade ihn als PNG oder SVG herunter.
  5. Scanne den fertigen Code vor dem Druck mit zwei verschiedenen Handys, zum Beispiel einem iPhone und einem Android-Gerät.

So funktioniert ein E-Mail-QR-Code

Der Code enthält einen Standard-mailto:-Link mit Betreff und Text. Beim Scannen öffnet das Handy das eingestellte Mailprogramm mit allen Angaben. Gesendet wird erst, wenn die Person auf Senden tippt.

Auf dem Handy muss ein Mailprogramm eingerichtet sein. Das ist meist der Fall. Wenn nicht, ist ein Link zu einem Kontaktformular die sichere Alternative.

Tipps

  • Nimm ein Sammelpostfach wie info@ oder kontakt@, keine persönliche Adresse, die sich ändern kann.
  • Lange Texte machen dichte Codes. Ein kurzer Betreff und eine Zeile Text lassen sich leichter scannen.
  • Sag, was passiert: "Scannen und uns schreiben" unter dem Code.
