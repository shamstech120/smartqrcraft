QR-Code aus einem Bild oder Screenshot scannen

Du kannst einen QR-Code auch scannen, wenn du kein Handy darauf richten kannst, zum Beispiel in einer E-Mail, einem PDF oder einem Screenshot.

  1. Speichere das Bild mit dem QR-Code oder mache einen Screenshot.
  2. Klicke oben auf Bild auswählen oder ziehe das Bild in das Feld. Einen Screenshot kannst du mit Strg+V (am Mac Cmd+V) einfügen.
  3. Das Tool liest den Code und zeigt den Inhalt: Link, WLAN-Daten, Visitenkarte oder Text.
  4. Prüfe das Ergebnis. Bei Links schaust du zuerst auf die Domain und öffnest sie erst dann.

Wird nichts gefunden, schneide das Bild näher am Code zu, nimm ein schärferes Foto oder füge einen weißen Rand um den Code hinzu.

QR-Code prüfen, bevor du ihn öffnest

Es gibt betrügerische QR-Codes, etwa Aufkleber über echten Codes oder Codes in unerwarteter Post. Den Inhalt zuerst zu lesen ist die sicherste Gewohnheit.

  • Domain prüfen. Passt sie zum erwarteten Unternehmen? Achte auf Tippfehler-Tricks und ungewöhnliche Endungen.
  • Vorsicht bei Zahlungsanfragen. Wer einen Code scannt, um Geld zu erhalten, macht etwas falsch. Verlangt ein Code eine Zahlung, prüfe Empfänger und Betrag.
  • Misstraue Zeitdruck. Codes mit Gewinnen, Erstattungen oder drängenden Fristen sind ein Warnsignal.
  • Aufkleber prüfen. Wirkt ein Code auf einem Plakat oder Automaten wie aufgeklebt, nutze ihn nicht.
  • Keine Passwörter eingeben auf einer Seite, die du nur über einen QR-Code erreicht hast, wenn du ihr nicht vertraust.

Warum lässt sich mein QR-Code nicht scannen?

Meist hat es eine einfache Ursache.

  • Das Bild ist zu klein oder unscharf. Nutze die Originaldatei oder einen Screenshot in höherer Auflösung.
  • Kein weißer Rand. QR-Codes brauchen leeren Platz um sich herum.
  • Geringer Kontrast oder invertierte Farben. Helle Codes auf dunklem Grund und blasse Farben sind schwerer zu lesen.
  • Der Code ist beschädigt oder zu dicht. Langer Inhalt erzeugt ein komplexes Muster.
  • Es ist kein QR-Code. Barcodes und Data-Matrix-Codes brauchen einen anderen Scanner.

Hast du den Code selbst erstellt? Prüfe ihn mit dem QR-Code Test, ob er auch klein gedruckt noch scannt.
