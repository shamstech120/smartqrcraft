Hilfe

Dein QR-Code wird lokal in deinem Browser erstellt. Es werden keine Daten an einen Server gesendet.

So wandelst du Text in einen QR-Code um

  1. Tippe oder füge deinen Text in das Feld ein.
  2. Achte auf die Vorschau: Je mehr Text, desto dichter wird der Code.
  3. Lade PNG oder SVG herunter.
  4. Scanne den Code einmal zur Kontrolle, besonders bei Umlauten und Sonderzeichen.

Wie viel Text passt hinein?

Technisch fasst ein QR-Code einige tausend Zeichen, aber dichte Codes lassen sich schlecht scannen. Als Faustregel:

TextlängeErgebnis
Bis etwa 100 ZeichenEinfacher Code, scannt auch klein gut
100 bis 300 ZeichenGut in normaler Druckgröße
300 bis 1.000 ZeichenDicht: größer drucken und sorgfältig testen
Mehr als 1.000Nicht empfohlen. Stell den Text lieber auf eine Webseite und verlinke sie

Ist der Text privat?

Der Text steckt im Bild selbst. Jeder, der den Code scannt, kann ihn lesen. Schreib also keine Passwörter oder persönlichen Daten in einen Code, den andere sehen. Der Generator läuft in deinem Browser, der Text wird nicht an unseren Server gesendet.
