Bild als QR-Code erstellen

Ein QR-Code kann kein Foto speichern, dafür ist er zu klein. Du kannst aber ein Bild online teilen und den Link als QR-Code drucken. Oder du nutzt dein Foto als Hintergrund eines QR-Codes.

Hilfe

Dein QR-Code wird lokal in deinem Browser erstellt. Es werden keine Daten an einen Server gesendet.

Weg 1: ein Bild per QR-Code teilen

  1. Lade das Bild in einen Online-Speicher hoch, zum Beispiel Google Fotos, Google Drive, Dropbox, OneDrive oder deine eigene Website.
  2. Erstelle dort einen Freigabe-Link und stelle ein, dass jeder mit dem Link das Bild sehen darf.
  3. Füge den Link oben ein und lade den QR-Code herunter.
  4. Teste den Code mit einem Handy, das nicht in deinem Konto angemeldet ist, damit du siehst, was Fremde sehen.

Weg 2: dein Foto im QR-Code

Im QR-Code Generator findest du unter Logo die Option Bild-QR (Foto hinter dem Code). Dein Foto scheint dann durch kleine Punkte hindurch. Der Code bleibt scannbar, sieht aber aus wie ein Bild. Download als PNG oder JPG; größere Punkte scannen zuverlässiger.

Für ein kleines Logo in der Mitte nutzt du stattdessen QR-Code mit Logo.

Datenschutz beim Teilen von Bildern

  • Jeder, der den Code scannt, kann das Bild sehen. Teile keine privaten Fotos über öffentlich ausgehängte Codes.
  • Frage Personen auf Fotos, ob sie mit dem Teilen einverstanden sind.
  • Du kannst den Zugriff jederzeit beenden, indem du die Freigabe im Online-Speicher aufhebst.
