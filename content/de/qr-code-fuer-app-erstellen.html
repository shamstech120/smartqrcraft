Hilfe

Dein QR-Code wird lokal in deinem Browser erstellt. Es werden keine Daten an einen Server gesendet.

So erstellst du einen QR-Code für deine App

  1. Öffne die Seite deiner App im App Store oder bei Google Play und kopiere den Link.
  2. Füge ihn oben ein und wähle einen Rahmen wie "App laden".
  3. Lade PNG oder SVG herunter und teste den Code mit dem passenden Handy.

Ein Code für iPhone und Android?

Ein Store-Link öffnet nur seinen eigenen Store. Ein App-Store-Link zeigt auf Android nur eine Webseite, nicht Google Play. Deine Möglichkeiten:

MöglichkeitSo funktioniert esPasst für
Zwei Codes nebeneinanderEiner mit "App Store", einer mit "Google Play" beschriftetDruck mit genug Platz, ohne Technik
Download-Seite auf deiner WebsiteEin Code führt zu deineapp.de/download, die Seite zeigt beide Stores oder erkennt das HandyEin Code, volle Kontrolle, funktioniert dauerhaft
Nur ein StoreWenn fast alle Nutzer dieselbe Plattform habenEinfach, schließt aber andere aus

Am besten: auf eine eigene Download-Seite verlinken

Ein statischer Code für deineapp.de/download geht nie kaputt, auch wenn sich deine Store-Links ändern. Die Seite kann beide Store-Buttons zeigen, oder ein Entwickler leitet je nach Gerät automatisch weiter.
