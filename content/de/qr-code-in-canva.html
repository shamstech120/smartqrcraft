QR-Code in Canva erstellen und einfügen

Canva hat eine eingebaute QR-Code-Funktion für Links, als statischen oder dynamischen Code. Für WLAN, Visitenkarten, Überweisungen oder ein kostenloses Logo erstellst du den Code besser separat und lädst ihn als SVG in Canva hoch.

Weg 1: die QR-Code-App in Canva

  1. Öffne dein Design in Canva.
  2. Öffne links Elemente und suche nach "QR-Code" (oder suche unter Apps).
  3. Wähle einen statischen Code (fester Link) oder einen dynamischen Code (Link später änderbar).
  4. Füge deinen Link ein, passe Farben und Ecken an und erstelle den Code. Er erscheint in deinem Design.

Menünamen können sich bei Canva ändern. Canva erstellt Codes für Links. Scan-Statistiken, ein Ablaufdatum und ein eigenes Logo im Code nennt Canva als Funktionen der Business- und Enterprise-Tarife. Ein dynamischer Code hängt vom Canva-Dienst ab, ein statischer nicht.

Weg 2: gestalteten QR-Code als SVG hochladen

  1. Erstelle deinen Code im QR-Code Generator: Link, WLAN, Visitenkarte, Überweisung und mehr, mit Farben, Rahmen und Logo.
  2. Lade ihn als SVG herunter. SVG bleibt in jeder Größe scharf.
  3. Ziehe die Datei in Canva in deine Uploads und von dort in dein Design.
  4. Skaliere den Code proportional und lass rundherum einen weißen Rand.

Tipps für den Druck aus Canva

  • Exportiere für die Druckerei als PDF (Druck).
  • Lege keine Effekte, Transparenz oder Schatten auf den Code.
  • Platziere den Code nicht über Fotos oder Muster, sondern auf einer ruhigen, hellen Fläche.
  • Drucke eine Probe in Originalgröße und scanne sie. Mehr dazu unter QR-Code drucken.
