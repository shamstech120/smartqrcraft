How to add a QR code to your visiting card

  1. Fill in your name, mobile number with +91, email, company and designation above.
  2. Keep to the details that matter. Fewer details make a simpler code that prints cleanly small.
  3. Download the SVG for your printer or designer; it stays sharp at any size.
  4. Place it on the back of the card, or in a corner on the front, at least 2 cm wide.
  5. Before printing 500 cards, print one on paper at actual size and scan it with two phones.

Design and printing tips

  • Size: 2 cm (about 0.8 in) is the practical minimum on a card. 2.5 cm is safer.
  • Quiet zone: keep a blank margin around the code; do not print text or borders right up to it.
  • Contrast: dark code on a light background. Avoid gold or silver foil for the code itself.
  • Finish: matte cards scan better than glossy ones under shop lights.
  • Add a line of text such as "Scan to save my number" so people know what it does.

What if my number changes?

The details are stored inside the code, so a new number needs a new code and new cards. If you change jobs or numbers often, make the code point to a web page you control, such as a LinkedIn profile or your own contact page, using the URL generator. Then you only update the page.
