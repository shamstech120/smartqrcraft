Was der QR-Code Test prüft

Ein QR-Code, der am Bildschirm scannt, kann auf einem kleinen Aufkleber oder einer abgenutzten Speisekarte trotzdem scheitern. Der Test lässt denselben Code unter härteren Bedingungen laufen und zeigt dir das Ergebnis.

  • In voller Größe lesbar: der Grundtest. Lässt sich der Code überhaupt lesen?
  • Verkleinert lesbar: halbe, viertel und sehr kleine Größe, um kleine Druckformate und Abstand nachzuahmen.
  • Leicht unscharf lesbar, wie bei einem Handy, das nicht gut fokussiert hat (sofern dein Browser es unterstützt).
  • Dunkel auf hell: zeigt invertierte Codes an, die manche Scanner nicht lesen können.
  • Kontrast: schätzt den Kontrast zwischen dunklen und hellen Modulen.
  • Länge des Inhalts: langer Inhalt ergibt einen dichteren Code, der mehr Platz braucht.

Das Ergebnis ist eine Orientierung. Im echten Einsatz zählen Handy, Licht, Druckqualität und Untergrund, daher solltest du den gedruckten Code trotzdem mit echten Handys testen.

QR-Code vor dem Druck testen

Eine kurze Routine spart teure Neudrucke.

  1. Exportiere deinen QR-Code als Bild (PNG) oder mache einen Screenshot.
  2. Lade ihn oben hoch oder füge ihn ein und lies Urteil und Checkliste.
  3. Behebe Warnungen: mehr Kontrast, kürzerer Link oder ein größeres Druckformat.
  4. Drucke eine Testkopie in Originalgröße und scanne sie mit mindestens zwei verschiedenen Handys (iPhone und Android).
  5. Teste den Code an dem Ort, an dem er hängen soll, bei echtem Licht und normalem Abstand.

Häufige Gründe, warum ein QR-Code nicht funktioniert

Diese Ursachen kommen immer wieder vor.

  • Zu klein für den Abstand, besonders bei dichtem, langem Inhalt.
  • Zu wenig Kontrast, etwa hellgrau auf weiß oder ein unruhiges Bild hinter dem Code.
  • Invertierte Farben (heller Code auf dunklem Grund).
  • Keine Ruhezone. Der leere Rand um den Code wurde abgeschnitten oder verdeckt.
  • Zu großes Logo in der Mitte, das zu viel vom Muster verdeckt.
  • Glänzende oder gewölbte Fläche, die spiegelt oder den Code verzerrt.
  • Falscher oder veralteter Link. Der Code scannt, aber die Seite fehlt.
