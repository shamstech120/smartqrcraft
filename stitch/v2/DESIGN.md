## Brand & Style

The design system projects authority, technical fidelity, and fluid creativity. Designed for high-velocity marketing teams, enterprise operators, and individual creators, the aesthetic balances the surgical utility of tools like Linear and Stripe with the approachable canvas clarity of Canva.

### Visual Style
- **Corporate Modern with High-Fidelity Tactility:** Clean layout architecture, calibrated neutral zinc surfaces, razor-sharp 1px border lines, and subtle multi-layered diffuse shadows.
- **Precision Utility:** Information-dense data displays balanced by generous white space in generation workflows, dynamic live preview surfaces, and tactile micro-interactions.
- **Emotional Intent:** Trustworthy, instant, frictionless, and premium. The interface communicates that generated digital assets are enterprise-reliable, scannable, and brand-tailored.

## Colors

The color palette centers on a vivid royal indigo foundation supported by electric violet accents, grounded by deep slate and neutral cool zinc foundations.

### Surface System
- **Base Canvas:** Pure White (`#FFFFFF`) for crisp contrast on core workspace cards, modal dialogs, and dynamic QR canvases.
- **Subtle Surface (Level 1):** Cool Slate 50 (`#F8FAFC`) for app shells, side navigation, and page canvas backgrounds.
- **Inset Surface (Level 2):** Slate 100 (`#F1F5F9`) for segmented controls, preview stages, table headers, and disabled field fills.

### Accents & Semantic States
- **Primary Brand Arc:** Vibrant Royal Indigo (`#4F46E5`) transitioning to Indigo 500 (`#6366F1`) for primary actions, active tabs, and primary analytics line graphs.
- **Secondary Creative Pop:** Electric Violet (`#7C3AED`) reserved for dynamic QR logic badges, high-impact conversion features, and premium/pro indicators.
- **Functional Validation:**
  - Success (Active Scan / Live): `#10B981` (Emerald 500) with `#ECFDF5` background.
  - Warning (Dynamic Limit / Expiring): `#F59E0B` (Amber 500) with `#FFFBEB` background.
  - Danger (Archived / Error): `#EF4444` (Red 500) with `#FEF2F2` background.

### Text & Border Rules
- Headings and high-emphasis labels strictly leverage `#0F172A`.
- Running body text, inputs, and standard icons strictly leverage `#334155`.
- Secondary metadata, helper text, and subtle placeholders utilize `#64748B`.
- Default structural borders use crisp `#E2E8F0`. Interactive borders elevate to `#CBD5E1` on hover and `#4F46E5` when focused, accompanied by a calibrated `#C7D2FE` focus ring.

## Typography

The type architecture pairs **Plus Jakarta Sans** for expressive, modern headings with **Inter** for dense, clean UI readability, dashboards, analytics, and complex configuration controls.

### Implementation Principles
- **Optical Tracking:** Tighter tracking on larger titles creates a polished, high-tech stance.
- **Tabular Figures:** All numeric tables, scan count statistics, coordinate panels, and analytics metrics must enable tabular figures (`font-variant-numeric: tabular-nums`) to prevent layout shifts during live data reloads.
- **Uppercase Labels:** Micro-badges, category markers, and QR matrix format labels use `label-sm` with slight uppercase tracking.

## Layout & Spacing

The design system operates on an uncompromising 8-point spatial base with a 4-point half-step (`0.25rem` / 4px) for inline items, micro-badges, and icon alignments.

### Grid & Viewports
- **Desktop (1280px+):** Fluid 12-column grid container capped at `1440px`. Column gutter is `1.5rem` (24px); page margins are `2rem` (32px).
- **Tablet (768px - 1279px):** 8-column layout. Gutter shrinks to `1rem` (16px); page margins remain `1.5rem` (24px).
- **Mobile (< 768px):** 4-column layout with `1rem` (16px) margins. Workspace shifts from two-column split screen (Configurator + Live Preview) into stacked tabs or a sticky preview drawer.

### Layout Workflow Rhythm
- **QR Studio Workspace:** Fixed left panel (`380px` to `440px`) containing accordion-driven parameters, bordered by a `1px solid #E2E8F0` divider. The canvas preview area takes remaining fluid space and centers the asset with a minimum `2rem` safety margin.
- **Dashboard & Fleet Management:** Standardized `1.5rem` row gaps between stat card grids, filtering bars, and dynamic list matrices.

## Elevation & Depth

Depth is established through soft, multi-layered shadows combined with hairline borders rather than heavy drop shadows, reinforcing a modern SaaS look.

### Elevation Hierarchy
- **Level 0 (Flat / Canvas):** Surface color `#F8FAFC` or `#FFFFFF`. No shadow. Bounded by `1px solid #E2E8F0`.
- **Level 1 (Cards, Static Panels, Field Containers):**
  - Shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.04)`
  - Border: `1px solid #E2E8F0`
- **Level 2 (Hover States, Interactive Cards, Segment Pickers):**
  - Shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.06), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`
  - Border: `1px solid #CBD5E1`
- **Level 3 (Dropdown Menus, Flyouts, Sticky Bars):**
  - Shadow: `0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.03)`
  - Border: `1px solid #E2E8F0`
- **Level 4 (Modals, Asset Exporters, Command Palettes):**
  - Shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`
  - Backdrop: `rgba(15, 23, 42, 0.4)` paired with `backdrop-filter: blur(4px)`.

### Specialty Preview Shadow
- **QR Stage Elevation:** The live preview card relies on a dedicated colored aura shadow: `0 20px 40px -15px rgba(79, 70, 229, 0.12), 0 0 0 1px #E2E8F0`.

## Shapes

The shape system leverages a refined modern curve strategy balancing rounded professionalism with tactile clickability.

### Radius Assignments
- **Small Elements (`8px` / 0.5rem):** Form inputs, tooltips, nested color swatches, dropdown menu items, code tags, and small icon buttons.
- **Medium Elements (`12px` / 0.75rem):** Standard buttons, badges, segmented pill controls, input card selectors, and modal action bars.
- **Large Elements (`16px` / 1rem):** QR configuration parameter groups, dashboard data tables, slide-over panels, and dialog windows.
- **Extra Large Containers (`20px` / 1.25rem):** Hero canvas stage, QR code live preview card, and subscription marketing cards.
- **Full Pill (`9999px`):** Status pills, live scan indicators, dynamic URL toggles, and floating action prompts.

## Components

### Buttons
- **Primary:** Solid indigo gradient (`linear-gradient(135deg, #4F46E5 0%, #6366F1 100%)`) with white text, `height: 40px` (desktop standard), `border-radius: 12px`, subtle inset highlight `box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.2)`. On hover: `filter: brightness(1.06)`.
- **Secondary:** Surface `#FFFFFF`, text `#334155`, border `1px solid #E2E8F0`. On hover: background `#F8FAFC`, border `#CBD5E1`.
- **Ghost / Tertiary:** Transparent background, text `#64748B`. On hover: background `#F1F5F9`, text `#0F172A`.
- **Destructive:** Soft red surface (`#FEF2F2`), text `#DC2626`, border `1px solid #FCA5A5`. On hover: `#FEE2E2`.

### Inputs & Selectors
- **Text Inputs:** Height `40px`, background `#FFFFFF`, border `1px solid #E2E8F0`, corner radius `8px`, typography `body-md`. Focus ring: `0 0 0 3px #C7D2FE`, border `#4F46E5`.
- **Color Picker Swatches:** Square `36px` cells with `8px` roundedness, interior saturation ring, and checkmark glyph on active state.
- **Checkboxes & Radios:** Size `18px`, radius `4px` (checkbox) or `9999px` (radio). Inactive border `1.5px solid #CBD5E1`. Checked state: solid `#4F46E5` fill with crisp `#FFFFFF` check/dot icon.

### Cards & Configuration Blocks
- **Config Section Card:** Surface `#FFFFFF`, border `1px solid #E2E8F0`, radius `16px`, padding `space-lg`. Hover transitions to border `#CBD5E1`.
- **Preset Style Selectors:** Grid cells showing QR pattern variations (dots, rounded squares, class blocks). Selected item: background `#EEF2FF`, border `2px solid #4F46E5`, elevation Level 1.

### Chips & Badges
- **Status Chips:** Height `24px`, padding `0 8px`, corner radius `9999px`, font `label-sm`.
  - Dynamic QR: Background `#F5F3FF`, text `#7C3AED`, border `1px solid #DDD6FE`.
  - Static QR: Background `#F1F5F9`, text `#475569`, border `1px solid #E2E8F0`.
  - Active: Background `#ECFDF5`, text `#059669`, with a pulsing 6px green indicator dot.

### Live Preview Canvas (Platform-Specific)
- Clean card container with `20px` radius, subtle grid dot background pattern (`radial-gradient(#CBD5E1 1px, transparent 1px)` with `16px` grid size), housing the real-time generated SVG canvas. Accompanied by floating format export chips (`.SVG`, `.PNG`, `.EPS`, `.PDF`) anchored in a bottom floating pill docked at `elevation-3`.
